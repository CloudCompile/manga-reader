## This software does not host content

The project does not host, store, upload, or distribute manga. It reads pages
that are already published on third-party websites, and the reader loads the
images directly from the host that publishes them, so image requests never pass
through the app. A proxy route still exists and is used automatically when a
host blocks direct loading; it fetches and forwards the image rather than
storing it. See the note on the proxy in `README.md` if you are deciding
whether to run this.
